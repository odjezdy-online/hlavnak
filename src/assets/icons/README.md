# Icons for the PID tablo look

The PID look never uses the gBUSE panel fonts; named tags in posts (`<logocd>`, `<metroa>` …) are drawn with these icons, emoji or small text boxes instead (see `PID` in `scripts/build-led-fonts.mjs`).

- `cd.svg`: the ČD emblem (dark blue #173A79), cut from [Ceske_drahy-logo.svg](https://commons.wikimedia.org/wiki/File:Ceske_drahy-logo.svg) on Wikimedia Commons, marked **public domain** there with a trademark notice. The logo is a trademark of České dráhy, a.s.
- `pid/`: pictograms from the PID virtual departure board (https://data.pid.cz/departures/), MIT License, © 2020 Pražská integrovaná doprava (`pid/LICENSE-PID-MIT.txt`). Copied from odjezdy-system.
